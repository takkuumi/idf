## 测试用例

### TC003: sys_evt task Stack canary panic 修复 ✅

**问题**:
```
Guru Meditation Error: Core 0 panic'ed (Unhandled debug exception)
Debug exception reason: Stack canary watchpoint triggered (sys_evt)
```

**根因**: `ip_event_cb` 内含 log::info! + 3次 fmt_ip + 字节转换 + config_modify (RCU clone), 总栈使用超 sys_evt 任务 2KB 默认栈。

**修复**: commit 8e148ef
- `ip_event_cb` 改为极简: 只读 ip_info, post `IoEvent::IpAssigned`
- main_loop 中处理 `IpAssigned`, 调用 config_modify 写 RCU
- sdkconfig.defaults 注释 `CONFIG_ESP_SYSTEM_EVENT_TASK_STACK_SIZE=2304`

**验证**: 设备启动 → got IP → main loop 处理 IPAssigned → 持续运行 27s+ 无 panic
