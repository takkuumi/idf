## TC007: BLE Mesh 清理 ✅

### 对照 MCA_F16V2_1_F48_BLE

| 项 | MCA (C++) | 本系统 |
|----|-----------|--------|
| BLE 协议 | GATT 自定义服务 | GATT 自定义服务 (一致) |
| Mesh 关键字 | 无 | 现已清理 |
| 命名 | name like "m" or "mesh" (Android 搜索) | 命名保留 (handheld 用) |

**结论**: BLE 不是 mesh 协议, 清理 mesh 相关代码。

### 清理内容

1. **删除** `src/ble_at/cfg_handlers.rs::handle_cfgmesh`
2. **删除** `src/ble_at/parser.rs::CFGMESH` 分支
3. **删除** `SystemConfig::ble_mesh_enable` 字段
4. **删除** `regs::CFG_BLE_MESH_EN = 0xFF11`
5. **删除** `cfg_handlers::handle_cfginfo` 中的 `ble_mesh=` 字段
6. **删除** `device::mod.rs` 中的 `ble_mesh` 日志
7. **删除** `config::ble_mesh` 模块 (NET_ID 等)

### 保留

- `AT+CFGBTNAME` (BLE 设备名称)
- `AT+CFGBTMAC` (BLE MAC)
- `AppError::Ble*` (BLE 错误类型, 重命名)
