# 2026-10-30 生产核查与修复

对象：台架 ESP32-S3R2，8MB Flash/2MB PSRAM，默认构建 v2.2.8，ESP-IDF v5.5.4。
IP `192.168.51.226`，串口 `/dev/cu.usbserial-1430`。硬件标识字符串不等于编译时
F3/F4 驱动选择，交付必须核对 BOM 和具体镜像。

## 修复内容

1. 运行时结果取消全局版本变化后的四次自旋失败；模拟量和 RS485 各自在短调度器互斥区
   复制最多 125 words，离锁后编码。无关配置不再因运行时更新误报非法地址；结果仍在 RAM。
2. 串行化组态表刷新，防止多个解析者反向发布旧表。
3. 模拟量 100ms 周期使用 wrapping 差值，修复约 49.7 天后每 tick 重复计算；延时/脉冲
   先扩展到 u32 再乘 1000，消除 65.535 秒饱和。
4. 脉冲同时预留开/关两条动作，满队列不撤销旧关断。每 tick 最多消费 8 条控制命令，
   Actor 每批最多消费 8 条消息，持续生产不再饿死周期任务。
5. 配置/文本快照读取前消费 dirty，成功后不清除并发新写；保存串行化，失败恢复 dirty。
6. DO 的 1 秒节流/去重 Flash 保存移到 DeviceActor；失败等待完整 100ms 后重试。
   PCA9555 在启用输出方向前写安全锁存器，消除缓存零与上电硬件高锁存器不一致。
7. UDP 在收包前检查配置，拒绝包洪流不再阻止热重绑。最近包超过 5 秒后接收状态失效；
   寄存器保留最后已知镜像，换配置/重建 socket 清除旧镜像。
8. 健康注册表用 CAS 预留有界槽位，不会短暂发布超出数组大小的计数。
9. Web 缺失/非法 IO、AI、BLE 字段拒绝，不能误改 DO0/AI0/名称；校准限定 12-bit，
   保留零回退和旧反向极性。密码限制 1..63 bytes、拒绝 NUL，并撤销旧会话。
10. 校准只遍历本变体声明的 AI 通道，不再选中八槽兼容区里未启用的通道。
11. Web 参数保存交给 DeviceActor，等待 ticket 完成，最多 8 秒；忙、队列满、错误、超时
    均不能返回保存成功。普通计划重启与 OTA END 也检查全部待落盘业务配置。
12. TCP 端口拒绝零、重复及 Web 的 80 端口；FC16 校验最终整组，允许合法端口交换。
    启动时只修复旧的非法 TCP 端口，避免一个坏配置使整个 Modbus TCP 无法启动。

## 中间候选失败与修复

中间候选把完整 Flash 屏障直接放进 HTTP 线程，在身份保存和恢复请求上两次触发
`Stack canary watchpoint triggered (pthread)`。失败证据保留在
`log/hardware/production-audit-delivery-serial-2026-10-30.log`。
后续改为 DeviceActor 执行、HTTP 等待确认，HTTP/Actor 栈预算仍为 10/12 KiB；
没有依靠加大栈掩盖调用链。最终结果以 `production-audit-actor-confirmed-*` 及复测日志为准。

恢复脚本首次只回写第二串口，无法恢复中间崩溃后第三串口回退的旧模式，因此报告恢复
不一致。脚本已回写备份中全部三个端口后重新验证，没有忽略差异或改写原始备份。

## 发布边界

本轮不替代 72 小时同一镜像长测、物理断电/Flash 中断、真实双光口、NFC 标签、
AI/AO 标准源、DI/DO 负载、手持机完整业务、全部 RS485 端口和异常总线、OTA 失败回滚。
LoRa、透明转发、Wi-Fi 自动故障切换及 BLE Mesh 业务不属于当前默认已完成能力。
缺少硬件的功能不能标为通过，也不作“100% 永不故障”承诺。
