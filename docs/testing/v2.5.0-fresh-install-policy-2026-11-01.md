# v2.5.0 全新安装策略

2.5.0 是新的生产基线，不把旧版本 NVS、holding、BLE Mesh 或存储数据作为兼容输入。首次交付必须全擦 Flash，再写入 bootloader、partition-table、otadata 和 factory 四段镜像。

2.5.0 的系统配置 schema 标记为 `0x0205`。没有该 schema 或 schema 不匹配时，系统使用 2.5.0 空配置；启动读取 ESP32-S3 eFuse 以太网硬件 MAC，生成 `IMC-<12位大写MAC>` 格式的 SN，并将配置落盘。

例如硬件 MAC 为 `FC:01:2C:05:64:BB` 时，SN 为：

```text
IMC-FC012C0564BB
```

SN 长度为 16 个 ASCII 字符，兼容现有手持机 18 字节窗口。2.5.0 不读取旧版本的 `ESP32-001` 或旧配置文件。未来高于 2.5.0 的版本如需保留现场配置，必须显式实现从 schema `0x0205` 的迁移，并通过独立验收后才能采用保留 NVS 的升级流程。

## 验收要求

- 全擦后启动日志出现硬件 SN 生成记录。
- SN 与芯片 eFuse MAC 一致，重启后保持不变。
- Web、BLE、Modbus FC=03/04 和 AT+CFGSN 返回同一个 SN。
- 手动写入自定义 SN 后重启，SN 不被硬件默认值覆盖。
- 未执行全擦的旧设备不纳入 2.5.0 生产验收。
