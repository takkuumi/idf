## 设备刷写状态

本次工作区检查未发现目标 USB 串口，仅有 `/dev/cu.BLTH`、`/dev/cu.Bluetooth-Incoming-Port` 和 `/dev/cu.GalaxyBuds8CA0`。因此没有对未知串口执行刷写。`release-flash.sh f3 --skip-build` 已执行 dry-run，确认会使用四段 `imc-v2.5.0-f3-*` 镜像并保留业务 NVS。

设备实刷需在 `/dev/cu.usbserial-1430` 重新出现后执行：

```bash
ESPFLASH_PORT=/dev/cu.usbserial-1430 ./scripts/release-flash.sh f3 --skip-build
```

刷写后必须从串口确认 `App version: 2.5.0`、build id 为本提交，且设备实际保存的网络配置仍符合现场设置。当前记录不把既有 2.4.0 实机数据冒充为 2.5.0 实机验收。
