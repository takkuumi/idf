# v2.6.0 F3 连续复位与持久化验收

日期：2026-11-03  
设备：F3，IP `192.168.51.226`  
串口：`/dev/cu.usbserial-1430`  
固件：v2.6.0

## 测试方法

1. 在复位前通过 Modbus TCP 502 读取并保存 RS485 配置、TCP 端口、IP/掩码/网关、BLE、AI 校准和完整组态区。
2. 通过 `espflash monitor` 的 Ctrl+R 连续复位设备 200 次，每次等待启动日志完整出现；串口原始输出追加保存。
3. 复位完成后重新读取同一寄存器窗口，并以大端序 16 位寄存器序列计算 SHA-256，逐字段和整体比对。

本测试覆盖软件/硬件复位启动循环，不等同于断电瞬间写入的掉电原子性测试。
