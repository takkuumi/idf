# 2.3.1 发布说明

日期：2026-10-31（Asia/Shanghai）。固件版本 `2.3.1`，Modbus 版本 `231 / 0x00E7`。

## 本版内容

- 将项目自有 NVS blob 写入统一到 IDF 原生同 key 版本替换接口，去掉
  esp-idf-svc 0.53.0 的预先删除操作，使相同值保存可使用 IDF 的免擦写去重。
- 保留原有 NVS key、存储布局、逐 key commit、dirty/失败重试、A/B、CRC 和回读边界。
- 覆盖系统配置、协议 A/B、设备文本、DO 位图、Web 信息和通用设备配置 blob。
- 纳入适配层主机回归、当前 IDF engine 的 24KB 容量/GC/113 个操作中断点/空间耗尽检查，
  并归档此前 F3 的保存与软件重启恢复结果。详细边界见
  `../testing/nvs-performance-optimization-2026-10-31.md`。

本版未更改 Q 点控制逻辑、Web 单管理员会话策略、硬件映射、分区或自动保存周期。

## 产物和板型

- `release/v2.3.1/default`：DEFAULT/F16，MCP23017。
- `release/v2.3.1/f3`：F3，PCA9555；当前连接板型。
- `release/v2.3.1/f4`：F4，PCA9555。
- 归档包：`release/esp32s3-gateway-v2.3.1-production.tar.gz`，附 SHA-256 文件。

每种型号目录含独立 app/bootloader/partition-table/otadata、ELF、新设备合并镜像、
`manifest.json`、`SHA256SUMS` 和烧录说明。现有设备升级使用独立烧录段，保留 NVS/holding；
`factory-new-device.bin` 仅供新设备，不能用于保留现场参数的升级。

## 本轮验证范围

使用原发布脚本清理对应构建目录后重新构建，并核对三种型号的生成 SDKCONFIG、版本、
分区、app 容量和逐文件 SHA-256。仅当前 F3 执行实际烧录；DEFAULT/F4 不因编译通过
被标记为完成实物验收。

烧录完成后只读 UART/Modbus 和公开登录页面，不登录 Web、不更改参数/输出、不执行
额外软件重启或压力测试。现场结果见 `log/hardware/release-v2.3.1-2026-10-31.md`。
