# IMC v3.0.0 生产发布说明

v3.0.0 基于 v2.7.0 生产存储基线，保留 2.7.0 及以后版本的配置与组态存储格式。本版重点修复手持机 BLE 组态保存与断开竞态。

## 修复内容

- 修复 BLE 断开回调过早取消分块组态上传的问题。手持机最后一个完整写帧已经进入固件请求队列时，断开不会再直接丢弃该帧。
- 断开清理前有限处理已完整入队的协议帧；协议分发锁忙时保留队列和槽位，下一次主循环继续处理。
- 修复旧连接的迟到 DISCONNECT 回调误清理新连接状态的问题。
- 只有清理条件满足时才取消尚未完成的组态暂存，避免“手持机收到写成功、设备实际未提交”的状态不一致。
- 延续 v2.10.0 的计划复位外设收尾，但正常 BLE 断开不会触发复位清理路径。

## 验证

- BLE 请求分发主机回归：9 项通过，覆盖断开后完成帧处理、协议锁忙重试、旧连接世代丢弃和队列满保护。
- 功能表契约回归：D0/D1 布局、RS485 轮询项、空配置、非法数据和重启恢复相关检查通过。
- 生产核心回归：28 项通过。
- NVS 适配回归：10 项通过。
- BLE 广播状态机回归：24 项通过。
- DEFAULT/F3/F4 生产镜像、分区地址、SHA-256 和 app 容量校验通过。F3 app 为 1,842,592 字节，占 2.25 MiB factory 分区 78.1%。F3 app 为 1,842,592 字节，占 2.25 MiB factory 分区 78.1%。

## 烧录

选择与硬件一致的 `default`、`f3` 或 `f4` 目录，发布包提供 bootloader、partition table、ota-data-initial 和 app 完整烧录镜像。v3.0.0 沿用生产存储分区布局；已有生产设备升级应保留 NVS 与 holding 分区，仅更新有效 app 分区，避免用新设备全擦流程清除现场配置。F3 app 为 1,842,592 字节，占 2.25 MiB app 分区 78.1%，满足 OTA 空间要求。
