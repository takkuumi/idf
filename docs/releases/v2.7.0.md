# IMC v2.7.0 首个生产基线

v2.7.0 是 IMC 的首个生产固件基线，产物对应 Cargo package `esp32s3-imc`、固件程序 `imc`。

## 全新安装

烧录 v2.7.0 前必须全擦 ESP32-S3 Flash，再写入对应硬件型号的完整镜像。不得保留开发版本的 NVS、holding raw 分区、OTA 选择记录或其他运行数据。发布包中的 `flash-command.txt` 和 `scripts/release-flash.sh` 已按此流程执行。

本版不导入 v2.6.0 或更早固件的数据：

- NVS 使用独立的 `imc` namespace，系统配置 schema `0x0207` / magic `IMCF`。
- 组态使用 IMC 专属协议 magic；holding A/B 槽使用 `IMC2` magic 和版本 1。
- 没有 v2.7.0 有效配置时，从本版出厂默认值启动；旧格式/旧版本数据不会被尝试迁移。

未来版本高于 2.7.0 时，只有明确实现并验收从 2.7.0 数据基线迁移，才能保留现场数据升级。设备寄存器映射和 BLE/Modbus 外部协议仍按本版产品定义运行。

## 发布矩阵

| 变体 | 功能 |
| --- | --- |
| `default` | MCP23017 默认板 |
| `f3` | PCA9555 F3 板 |
| `f4` | PCA9555 F4 板 |

命令：`just release`。输出位于 `release/v2.7.0/{default,f3,f4}`，含 app、bootloader、分区表、初始 OTA data、工厂镜像、SHA-256 清单和 manifest。
