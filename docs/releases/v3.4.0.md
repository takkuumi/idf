# IMC v3.4.0 发布说明

日期：2026-11-15

## 发布内容

- 修复 AI 无有效零点标定时，将 ADC 空载偏置通过默认参考换算成约 100～200 有效值的问题。未标定通道不再发布伪有效量；原始 ADC 仍保留诊断，Web 显示未标定。已存有效端点不会被自动更改。
- Modbus TCP 最多接纳 9 个客户端会话，允许 8 个业务客户端同时连接并留出一个管理/现场会话槽。增加活动连接和拒绝计数，便于现场判断连接容量问题。
- 保留并随版本封板 3.3.0 的 F3 RS485-1 粘帧修复、UART 时序边界修复、BLE 广播自愈与全链路验证结果。

## 验证

- AI 转换 host 测试：11/11；生产核心 host 测试：28/28。
- TCP 调度、寄存器边界、RS485 时序、BLE 广播恢复、BLE/NFC 分发、NFC mailbox、IO 事务、组态表格、RCU、NVS 和复位保存屏障测试通过。
- F3 真机空载 AI 验收：4 路各 120 次；scaled 全为 0，raw 2947～2950，无换算核验错误。该设备保留了已有现场零点端点。
- AI 空载根因、旧固件行为与实机结果见 [`v3.3.0 AI 空载调查`](../testing/v3.3.0-ai-no-input-2026-11-15.md)。
- TCP、RS485、BLE 并发压力数据见 [`全链路压力验收`](../testing/v3.3.0-full-link-stress-2026-11-15.md)；RS485 分档延时与吞吐见 [`RS485 分档测试`](../testing/v3.3.0-rs485-read-size-throughput-2026-11-15.md)。

## 兼容与安装

- 3.4.0 沿用 v3.3.0 的分区表和存储 schema；同硬件型号仅使用对应变体固件。升级前请按 OTA 指南核对设备当前分区布局和 App 文件。
- Web OTA 只上传对应型号的 `imc-v3.4.0-<variant>-app.bin`；`ota-data-initial.bin` 仅用于新设备完整烧录，不是 OTA App。
- `factory-new-device.bin` 是全新设备完整刷机镜像。它不保留现场 NVS；已有设备升级不要全擦，除非明确要清除配置并已备份。
- 交付包由 `release/v3.4.0/` 下各型号目录提供，具体构建 commit、分区偏移、文件大小和 SHA-256 以各目录 `manifest.json` 与 `SHA256SUMS` 为准。

## 验收边界

本版未使用标准 4–20mA 源进行 AI 全量程精度测试；无电流输入 raw 基线不是 mA。完整链路压力是台架有限时长结果，不代表 7×24 长期可用性统计。现场上线仍应按设备硬件型号执行对应 IO、RS485 和业务组态验收。
